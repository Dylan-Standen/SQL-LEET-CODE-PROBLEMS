# 1757. Recyclable and Low Fat Products
[Problem link](https://leetcode.com/problems/recyclable-and-low-fat-products/description/?envType=study-plan-v2&envId=top-sql-50) · Easy · `WHERE`

## Problem (in my own words)
Simple problem where we are asked to select all Product that are both Low Fat and Recyclable. 

## Approach
Let the table be the (multi)set

$$
P \subseteq \mathbb{N} \times \{Y,N\} \times \{Y,N\}
$$

## Solution
```sql
SELECT product_id
FROM Products
WHERE low_fats = 'Y' AND recyclable = 'Y';
```

## Pitfalls
- `= NULL` is never true → use `IS NULL`
- `COUNT(amount)` would return 0: COUNT(col) skips NULLs
